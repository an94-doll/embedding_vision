## 固定点序

以物体设定的顶部朝上观察，从左上角逆时针编号：
P1 左上角 → P2 左下角 → P3 底边中点 → P4 右下角 → P5 右上角。
有三个矩形凹槽的一侧为底部。
在本组原始拍摄方向下，P1/P5 位于图像下方，P2/P3/P4 位于图像上方。
后续标注应追踪相同实体点，不按画面位置重新编号。

关键点逐图目测定位，P3 取 P2/P4 的几何中点。
圆角按相邻直边的延长交点近似定位，检测框覆盖主体及下缘凸起。
五个关键点均可见，visibility=2。

每行 20 列：class cx cy width height P1x P1y P1v ... P5x P5y P5v。
检测框和关键点坐标按对应的 720×720 图片归一化。
配置为 kpt_shape: [5, 3]，flip_idx: [4, 3, 2, 1, 0]。
`pose_schema.yaml` 仅提供类别和关键点配置；训练时需另行配置数据路径和训练/验证集。
