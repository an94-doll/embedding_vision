# 05 组正面标注

图片 images/05 共 28 张 720×720 图像；labels/05 共 28 个标签，每图 1 个主体，类别 0（front，正面）。
本组主体均完整，跳过 0 张；有效图片列表为 annotations/05_valid_images.txt。

白色矩形斜面所在侧为底部，本组在图像右侧。
以物体顶部朝上观察，从左上角逆时针编号：P1 左上 → P2 左下 → P3 底边中点 → P4 右下 → P5 右上。
左右以物体方向为准，跟踪相同实体点，不能按图像位置重新编号。
P2/P4 取正面栅格面与白色斜面的交界两端；P1/P5 取栅格面另一侧的两个角。
均以同一栅格面为准，不使用厚度面的外角；圆角、斜切角和凸舌位置按主面的直边延长交点近似定位。P3 为 P2/P4 图像坐标中点。
检测框覆盖整个物体，包括斜面、侧壁和凸舌。

五个点均可见，visibility=2。每行 20 列，位置按当前 720×720 图像归一化。
沿用 annotations/pose_schema.yaml：0 front，1 back，kpt_shape [5,3]，flip_idx [4,3,2,1,0]。
本目录 jpg 为原尺寸叠加标注，annotations/05_review_*.jpg 为分批核查图；像素坐标见 05_points.json。
模糊、反光和斜面交界区域存在人工目测误差，坐标格式检查不等同于三维共面测量。

已逐张核查全部叠加预览，检查主体完整性、按物体方向编号、斜视厚度面、圆角交点及底边斜面交界。数量、格式、坐标、框内点位、中点和逆时针顺序检查均通过。
