# 白盒与铁篮四角数据集（已复核）

477 张图片及同名 TXT 标签；17,423 个白盒实例、477 个铁篮实例。

images/：原始图片。
labels/：最新保存的 YOLO Pose 标签，每行 17 列。
review_state.json：导出时的复核记录。
validation_report.json：导出统计与校验结果。

类别 0 = white_box：点 0 左端点，点 1 右端点，点 2/3 为零占位。
类别 1 = basket：点 0 左上，点 1 右上，点 2 右下，点 3 左下。
角点取金属本体外沿，不含白色支架；无法定位的点为 0 0 0。
坐标及框归一化到图像宽高；可见点 visibility=2。
kpt_shape: [4, 3]
flip_idx: [1, 0, 3, 2]

本包不划分训练/验证集；视频相邻帧在后续划分时应避免跨集合造成泄漏。
