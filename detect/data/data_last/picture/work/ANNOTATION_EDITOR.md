## 操作

- 默认仅显示左右端点及连线。勾选“显示边界框”或“显示编号”可分别开启；需要改框时再打开。
- 拖动已有端点修正位置。右侧选择目标后，用“左端点 1”或“右端点 2”在图上重新点选，补齐缺失端点。
- 新增盒体：点击“新增盒体 B”，拖出可见正面范围，再依次点击上述明显长边的左、右端点。创建时临时显示框以便定位，完成后遵循显示开关。
- 看不清或出画的点勾选“不可定位”，保留为 0 0 0。右侧列表会显示缺几个点，即使隐藏黄框也能找到。
- 可删除误标、撤销/重做、滚轮缩放，按住空格拖动画面。关闭“显示标注”可对照原图。
- “保存为待复核”只保存，不加入训练。“同意参与训练”保存并加入训练清单；“同意并下一张”可连续检查；“不参与训练”保存但排除。修改决定后清单同步更新。

本次修订的候选保持待复核，不会自动批准；用户已批准的图片保留原状态。待复核不表示图片被判定不可用。可筛选“仍有缺失端点”优先补点，也可检查和修改其余图片。

## 文件

- `images/train/`：未绘制标注的原分辨率副本。
- `labels/train/`：同名 YOLO Pose 标签，类别 cassette_front，每目标 11 列。
- `previews/`：端点和连线预览。
- `batch_train.txt`：仅列出用户批准的图片，随保存更新。
- `data.yaml`：2 个关键点，每点 x/y/v，左右翻转索引 [1,0]。验证集留空；训练前需要划分。
- `batch/frame_review_status.csv`、`batch/export_summary.json`：随保存更新的状态和统计。
- `batch/editor/history/`：每次保存前的备份。
- `batch/CHECK_REPORT.md`：交付检查报告。
